# desc: 从 PDF 文本提取结构化学习计划任务（输入：PDF 纯文本）
请从以下从 PDF 学习计划文档中提取的纯文本中，识别所有「学习任务」，并提取为结构化 JSON。

提取字段（每个任务一项）：
- date: 任务日期，格式 YYYY-MM-DD。原文若写「7月20日」「2026/7/20」「2026.7.20」请归一化为 2026-07-20；无法推断年份时默认 2026。
  **重要**：若日期是相对表述（如「今天/明天/下周/本周」）或年份/月份缺失到无法可靠推断，请设 date 为 null，并在 date_note 中说明歧义（例如「相对日期，需用户确认」）。不要猜测具体日期。
- date_note: 当 date 为 null 或存在歧义时的说明；日期明确时设为 null。
- subject: 科目，尽量使用标准名：数学、英语、政治、408（如「高数/线代/概率」→数学，「数据结构/计组/操作系统/计网」→408）。
- content: 任务内容（简要，如「极限专题训练」）。
- start_time: 开始时间 HH:MM，无则 null。
- end_time: 结束时间 HH:MM，无则 null。
- status: 固定为 "pending"。
- confidence: 你对本次提取准确度的自评，0 到 1 之间的小数（0.9 表示很有把握，0.5 表示不确定）。
- reason: 简短说明该条任务为何被如此提取（如「原文第二行明确列出」），便于用户复核。

输出要求：
1. 只输出一个 JSON 对象，不要任何解释或 markdown 代码块。
2. 结构：{"tasks": [ {...}, ... ]}
3. 若文本中没有明确任务，输出 {"tasks": []}
